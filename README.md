# Printable Tiled Road Map

Generate multi-page printable road maps from an address. Print the pages and tape them together.

**Live demo:** [https://awheelis.github.io/printable-tiled-road-map/](https://awheelis.github.io/printable-tiled-road-map/)

## How to use

1. Open the [live demo](https://awheelis.github.io/printable-tiled-road-map/) (or open `index.html` locally).
2. Enter an address, radius, and max number of pages.
3. Click **Generate PDF**.
4. Print the PDF at **100% scale** and tape the pages together.

Road names are kept readable by using a high enough zoom level.

## Notes

- Works best for neighborhoods and small areas (roughly 0.5–5 miles).
- Uses OpenStreetMap tiles.
- Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.
